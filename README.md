# Тёплый знак — сайт

Минималистичный одностраничник: каталог (4 открытки и сборник анекдотов), «О магазине», «Доставка и оплата», «Контакты», FAQ, корзина с короткой формой заказа.

- `index.html` — весь сайт, CSS и JavaScript внутри.
- `assets/img/` — логотип и изображения товаров.

Открыть локально: двойной клик по `index.html`. Опубликован на GitHub Pages: https://kek8atya.github.io/teply-znak/

## Что поменять перед запуском

В `index.html` такие места помечены комментариями `TODO`:

- **Контакты:** почта, Telegram, VK — блок «Контакты».
- **Приём заказов:** `CONFIG.orderEndpoint`. Пока он пустой, заказ показывает «Спасибо» и никуда не отправляется (демо-режим).
- **Оплата и Ozon:** ссылка на оплату (карта, СБП) и виджет выбора пункта выдачи Ozon.
- **Аналитика:** код Яндекс Метрики и VK Пикселя — в `<head>`.
- **Документы:** политика конфиденциальности и оферта — шаблоны, данные в [скобках] заполнить и согласовать с юристом.
- **Товары:** цены, тексты и картинки — список `PRODUCTS` в начале скрипта.
